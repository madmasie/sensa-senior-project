# Python dependencies for the Sensa PM2.5 calibration project.
#
# PREFERRED: install everything from the tools/ directory instead:
#   cd tools && pip install -e ".[ml]"
#
# This file is kept as a fallback for environments that prefer plain
# requirements files (e.g. some CI systems).
#
# NOTES ON GPU SUPPORT:
#   - NVIDIA GPU: replace 'torch' below with the CUDA-enabled wheel from
#     https://pytorch.org/get-started/locally/
#   - AMD GPU on Windows: PyTorch does NOT support AMD (ROCm) on Windows.
#     Training will run on CPU, which is fast enough for this tiny model.
#   - AMD GPU on Linux: install the ROCm wheel instead (see pytorch.org).
